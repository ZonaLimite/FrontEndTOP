      Necesito desarrollar un algoritmo que analice un string "trace" y determine que
      trazas son aquellas que hacen mencion a eventos de ocultacion o desocultacion de fotocelula.
      "trace" es un string que contiene una traza de otro sistema
      Vamos a desarrollar un algoritmo que analize el contenido de trace y valide cual de cada una de esas
      lineas de traza representa comandos de activacion/desactivacion de fotocelulas

      el string trace es una cadena con contenido de traza que hay que analizar, para detectar que
      trazas son aquellas que hacen mencion a eventos de ocultacion o desocultacion de fotocelula.

      Las trazas que incorporan la cadena "RE" indican la activacion ("ocultacion") de una fotocelula
      Las trazas que incorporan la cadena "FE" indican la desactivacion ("desocultacion") de una fotocelula

      Las trazas que incorporan la cadena "clearTrackingPoint" indican, igualmente, la desactivacion ("desocultacion") de una fotocelula
      Las trazas que incorporan la cadena "onTakeMailPiece" indican, igualmente, la activacion ("ocultacion") de una fotocelula
      En este tipo de trazas el nombre de la fotocelula va a continuacion de la cadena "sur" 

      Por ejemplo la siguiente cadena :
        C30100040 18:07:11:268 INF IL1_MAIN - BeltConveyor FE 4001B256 sur CUL-B5 a 55030179
      puede interpretarse como "activacion de fotocelula "CUL-B5" porque contiene "RE" y "sur CUL-B5"

      Hay un caso especial en las cadenas que incorporan la cadena "TakeMailPiece()".
      En ese caso la fotocelula es la que aparece a continuacion de "TakeMailPiece()" despues de la cadena "from"
      Por ejemplo la cadena:
        C30100040 18:07:09:231 INF IL1_FE2_ - rootOnFeedingReport(), MailPiece created 0x73de444, Id=4001B256 ApxId=193
      puede interpretarse como "activacion de fotocelula "FE2" porque contiene "TakeMailPiece()" y "from FE2"

      necesito desarrollar un metodo que reciba como parametro el string "trace" y devuelva como respuesta 
      un array de objetos. Cada objeto debe tener la siguiente estructura, representando cada evento de activacion/desactivacion
      de fotocelula detectado:

        {
          fotocelula: string,
          evento: 'activacion' | 'desactivacion'
        }
      o 
        null, si no hay deteccion de activacion/desactivacion de fotocelulas en el string trace.

      Desarrolla este algoritmo solo en typescript, sin usar librerias externas, sobre un nuevo servicio
      sobre la carpeta "services", llamado  "TraceProcessorService".
